# Data Studio 重构前后功能与交互对照

日期：2026-10-11。旧版基线 `ea68e423`（`f159053e` 的父提交）；新版为 `f159053e` 加当前工作区的功能接通与 review 修复。通过源码差异、旧版回归测试和两版浏览器页面核查。本轮没有修改产品源码。

## 结论

在核查范围内未发现核心业务入口或 API 方法因重构被移除。原有 52 个 API 方法调用仍存在，`frontend/src/api/`、共享 `SqlEditor.vue`、`PersistentTabs.vue`、Java、DataAgent 与部署代码相对基线无差异。不过交互并非完全等价：血缘常驻分栏及其高度拖拽已取消，窄栏的精确血缘连线不再直接展示，若干操作移入菜单。API 方法保留只能证明接线覆盖，不能证明每条真实写路径已经通过联调。

## 页面核对与限制

两版用同一 `demo_store_sales_daily` 与同一 SQL，均返回 3 行、相同字段与金额；旧版常驻血缘节点及新版血缘页签均有相同上游表/写入任务。新版完整目录仍显示相同注释、行数、存储和上下游统计，更多菜单包含引擎配置、访问统计和变更记录，已实际进入引擎页。

配对截图按约 1440×900 CSS 窗口核对。两版树/右栏宽度和旧页签数量保留各自页面状态，不能把截图当作尺寸完全一致的像素测试。截图取应用内容范围，移除浏览器截图多余的外部白边。演示 fixture 的连接显示名及后续添加的分区/版本样例有差异，因此 API 接线以正式源码比较，不以样例数量比较。

旧版开发预览首次依赖优化后未稳定显示，改用完成构建的 preview 后页面核对通过；本轮临时 4175 服务与对照页已关闭，用户 4174 服务与页面保留。仅执行演示读取/查询，没有真实写库、发布或模型调用。真实服务的上一轮覆盖和剩余边界见 [功能 Review](2026-10-11-datastudio-review-and-wiring.md)。

## 后续判断

1. 若目标是业务功能完整保留，当前未发现需恢复的漏接按钮；优先完成真实 Doris 写操作、Dolphin 保存/发布、智能元数据模型生成/采纳联调。
2. 若要求旧版所有交互等价，需要单独决定血缘常驻分栏/高度拖拽和窄栏精确连线是否恢复。它们属于目前已确认的编辑器布局取舍，本轮不擅自推翻。
3. 为让少一步点击的旧操作更易找，可后续增加快捷键/工具提示，或在血缘列表保留任务与上下游的关系摘要；不用恢复整页多层卡片。只读 SQL 保存为任务仍须遵循后端输出表契约，不应仅移除前端校验。
