# Data Studio 编辑器工作台视觉设计

## 现状与目标

左侧已有数据源 → 数据库 → 表/视图分组的懒加载树，但表节点使用多行卡片、数据量底纹和四种统计标签，弱化了层级。三栏独立圆角边框、查询内部卡片和结果卡片占用空间，窄屏工具栏容易拥挤。领导演示需要清晰、克制的数据库工具界面。

## 范围与方向

只修改 Vue 3 / Element Plus 前端展示和局部交互；Java、DataAgent、API、数据库和部署契约不变。保留查询、元数据编辑、血缘、懒加载、Tab 恢复和水平拖拽。用户已确认按第十四版原型1:1落地，正式实施以该版布局、颜色、字号和交互为验收基准。保留原型截图和累计源码补丁用于对照。

内部比较三种方向：压缩现有卡片、数据库编辑器、以搜索为主的资产浏览器。选择数据库编辑器：连续三栏、浅色资源树、白色编辑面、细分隔线和蓝色激活态。

## 设计

- 导航“Agent问答”改为“智能问数”，与已有路由标题一致。
- 顶层明确为“数据源连接”，使用连接图标、连接名称和数据库引擎类型，结构为连接 → 数据库 → 表/视图 → 对象；保持现有数据源 ID、激活/懒加载和查询绑定契约。演示数据中的连接名称改为“演示 Doris 连接”，实际连接保留用户配置名称。
- 左侧提供“紧凑视图 / 完整视图”，默认紧凑；入口为搜索框右侧的视图选项图标，下拉菜单用勾选标记当前模式，避免与排序混用分段按钮。字号统一 10px：简洁模式为 24px 单行对象名；详细模式为 36px 两行节点：首行对象名，次行注释与行数/存储/上下游统计；注释过长截断并提供悬停全文。父节点始终保持 24px。两种模式共用同一棵树，不清空展开、搜索、排序与选中状态；14px 层级缩进、层级引导线；允许多个分支同时展开，点击父节点展开/收起。简洁模式的信息可在悬停和对象详情查看；详细模式统计采用无色块的紧凑文字，低对比度细线保留相对行数分布。保留元数据缺失警告、数据库与分组计数、数据源状态、可视范围统计加载，以及常驻的逐数据源/数据库刷新入口。完整信息仍有悬停提示。
- 删除“数据资源”标题行，将全局刷新和新建表移至搜索框旁；排序收进搜索行右侧的排序图标菜单，菜单按“排序依据 / 排列方向”分组并勾选当前值；移除常驻排序行，顶部只保留一行搜索与工具图标。排序只更新已加载对象分组的叶节点，不重建数据库分组，保留展开与当前选中对象。
- 删除重复的“Data Studio / SQL 工作台”顶部工具栏；新建查询使用标签栏“＋”（空状态保留新建按钮），对象详情显隐移至标签栏右侧；统一外框、移除三栏独立圆角卡片。标签单行、SQL/结果通过分隔条组织。
- 字号采用10/11/12px层级：目录及辅助信息10px，工具栏/标签/结果/详情正文11px，SQL与对象标题12px。标题字重500，概览和访问指标分别14/16px。
- 详情头部按“对象名 → 所属连接 / 数据库 → 独立描述 → 标签与操作”排列；对象名用12px/500字重，描述11px可换行，标签为中性轻底色，完善度为辅助文字。底行标签居左、按钮居右，“编辑”为主按钮，“智能元数据”为次按钮，“删除”移入更多菜单；窄栏底行自动换行，编辑态仅保留取消/保存。
- 右侧详情可收起，保留挂载及编辑状态；元数据各 Tab 同步扁平化；血缘移为独立 Tab，按需打开，移除常驻上下分栏以完整展示对象详情。描述列表继续按实测宽度选择列数。
- 默认左栏 22%（为表名与恢复的统计留出空间）、右栏 28%，下限分别 220px / 320px；窄工作区工具栏换行，避免按钮遮挡。窄屏改为可滚动的纵向排列。

## 中间工作区原型细化

- 查询标签紧贴工具栏，移除内容区的默认留白。执行动作居左，执行作为唯一蓝色主按钮；停止使用图标与文字，存为任务为次操作，重置放入更多菜单。
- 所有查询标签保留可选择连接和Schema的下拉框，表对象身份与执行上下文分别保存。结果行数上限通过“200 行”入口弹出设置，避免数字步进器常驻。
- 结果标签统一中文（执行信息、结果 1、查询历史）；结果工具栏仅保留状态、行数、耗时，时间与批次详情通过悬停及执行信息查看。表格 / 图表使用轻量按钮切换，导出采用有提示的图标。
- 数据网格增加固定序号列、浅色表头、细列分隔与 28px 行高。信息、历史和图表采用同样的扁平布局。保留查询、取消、保存、结果集、图表与导出行为。

## 中间工作区第五版

- 参考 Navicat 查询工具栏，使用“执行 / 停止 / 解释”图标加文字；主动作保留蓝色执行按钮，保存任务作为次操作。

## 页签新增与溢出

新增查询加号紧随已显示标签，作为页签栏正常布局项；仅为右侧详情开关预留空间。标签未溢出时不显示左右滚动箭头；超出剩余可用宽度时使用 Element Plus 原生测量与滚动，保持新增按钮可见。关闭标签后箭头自动消失。

- 字段、DDL、引擎配置、访问、新鲜度、变更和血缘统一中性表头、11–12px 字号、浅色分隔及平直框架，保留各组件自身边框，避免再套卡片。

## 权衡

10px 是用户要求的高密度目录字号，依靠行高、对比度和图标维持定位。简洁模式用于快速定位，详细模式用于信息扫读与比较，去掉卡片边框、彩色标签底色与大面积统计底纹。详情 Tab 在窄面板保留原生滚动导航，优先给 SQL 编辑区域留空间。

## 功能接通（2026-10-10）

依据[功能接线核查](../reports/2026-10-10-datastudio-function-audit.md)修复入口与状态问题，视觉保持第十四版不变。

- **新鲜度演示只读**：配置、保存、删除和立即检查在正式环境都会写入配置或检查快照，演示环境与其他写操作一致禁用并给出原因；“历史”保留可看。演示数据是固定的定时检查样例，概览最新结果即历史第一条，每条记录满足“检查时间 − 最新数据时间 = 数据年龄”；mock 不再提供立即检查接口，写请求统一被拒绝。页内标明“演示样例”。
- **新鲜度切表竞态**：请求带序号，只采纳最近一次且仍属当前表的响应；切表先清空旧结果，加载失败就地显示失败与重试，不回落为旧表数据或“未配置”。字段下拉和历史弹窗同样丢弃非当前表的迟到响应。
- **分区切表竞态**：分区加载中与错误按“tab + 表”记录，切到新表不再被上一张表的请求挡住；迟到结果只写回发起它的 tab state，错误只显示在对应表上。
- **引擎配置编辑入口**：引擎配置页头部直接提供“编辑”，复用概览的 `startMetaEdit/saveMetaEdit/cancelMetaEdit`，与概览共用同一表单和确认提交，禁用原因相同（缺平台元数据、未选集群）。编辑态说明保存会直接对 Doris 执行 ALTER；无分桶字段时分桶数不可改，有分桶字段时说明只影响之后新建的分区；副本数仍提示建议≥3。分层缺失时提示到概览补齐。真实联调发现 `el-input-number :min="1"` 会把未同步（null）的分桶数/副本数改写成 1，保存时被当成修改并对 Doris 发起 ALTER；因此只有分桶字段存在且分桶数已知时才给分桶输入框，副本数已知时才给副本输入框，否则只读并说明原因。

### 存为任务与调度数据源

现状：门户连接是 `doris_cluster`（id、名称、类型、FE 地址），Dolphin SQL 任务按 `datasourceName` 引用 Dolphin 自身的数据源目录（`GET /v1/dolphin/datasources` 仅返回 id/名称/类型/库名/备注，且随 `dolphinConfigId` 变化）。两者之间没有任何持久化映射，Dolphin 选项也不含主机端口，因此前端无法证明某个调度数据源就是当前查询连接。按名称、库名或类型匹配都是猜测，可能把任务写到错误集群。

本次（无契约变更）：

- `saveAsTask` 以结构化 `queryTarget`（连接 id、连接名、Schema）打开任务抽屉，仍沿用执行目标而非检查对象；描述文本补充连接名。
- 抽屉在 SQL 节点的数据源上方显示查询目标，并说明“门户连接与调度数据源暂无映射，请选择对应调度数据源；不会自动匹配”。从 Data Studio 打开时数据源为必填，不预选任何项。其他入口行为不变。

后续独立功能（本轮不新增数据库契约）：显式绑定门户连接 + Schema + Dolphin 实例到稳定的数据源 id。不能仅按 `(cluster_id, dolphin_config_id)` 绑定名称：同一连接有多个 Schema，而 Dolphin 数据源包含默认库；名称也可被重命名。绑定维护与目录失效校验需要同时设计，失效后回退显式选择，不按名称推断。

## 2026-10-11 Review 后续修复

范围仅涉及 Vue 前端、测试与演示 mock；不修改 Java API、DataAgent 或部署契约。Claude 的功能修复合入当前主工作区后继续审查。

- 对象操作使用对象所属连接（table.sourceId / table.clusterId），不使用 SQL 执行连接。仅旧状态没有对象连接时沿用当前连接兼容。保存、字段变更、删除、智能元数据取值/采纳和分区请求在异步确认前锁定连接与对象。
- 新鲜度所有异步链路按当前表上下文隔离，包括字段、历史、检查、保存和删除。删除确认展示表名，确认期间切表取消该操作；旧操作完成不关闭新表编辑，也不覆盖新表数据或加载态。表切换关闭旧历史窗口，卸载使旧请求失效。
- 分区加载失败不缓存成成功的空列表；再次进入允许重试，错误不被误展示为“暂无分区”。
- 任务数据源目录加载失败或为空显示可操作提示，调度实例切换不沿用上个实例的数据源选项；修复任务抽屉未导入的状态图标。门户与调度数据源自动映射作为独立后续功能，本轮保留显式选择，不按名称猜测、不新增绑定表。

验收包含延迟响应/确认框期间切表、查询连接与对象连接不同、数据源目录空/失败等回归；正常和演示构建，真实服务的只读查询与页面烟测。真实 Doris ALTER 和 Dolphin 发布只在可用环境验证，不将 mock 通过等同于端到端完成。

- 正式页面烟测补充：停止查询的显示耗时/时间沿用上次执行，修正为本次执行的时间；停止响应按 runId 隔离，不能取消后续新查询。抽屉初始化中禁止提交，避免查询 SQL 尚未预填时编辑被异步覆盖。

### 2026-10-11 MySQL 真实验证补充

表信息保存接口返回的是部分更新实体，其未传入的数据库、所属连接、同步状态和统计字段为 null。前端直接展开合并会清空详情，并影响后续 Tab key 与对象操作。保存成功后重新读取该表的完整元数据，再更新详情及目录缓存，继续以对象原有连接为目标。同步状态的后端修正复用 `2026-06-22-data-table-source-type-design.md`，不扩大本设计的布局范围。

## 2026-10-11 真实验证后续：编辑限制与路由优先级

已同步 MySQL 表的已有字段不提供主键在线切换，并在保存前再次校验；新字段添加主键和平台草稿保持既有能力。Doris 限制保持不变。

工作区初始化期间暂停标签对 URL 的反向写入，先恢复缓存、加载连接，再按传入路由打开目标对象；路由优先于缓存激活项，缓存 SQL 与其他标签保留。嵌套路由同步与异常退出恢复原抑制状态，初始化结束后恢复普通标签切换。

字段编辑提交保留未设置默认值的 NULL，避免仅修改注释时将 NULL 改为输入空串而引入一次无实际变化的同步记录。比较工具仍将未设置值与空白输入按既有规则比较，避免未修改的字段被批量提交；用户主动清空输入仍按原有清空默认值协议提交。
