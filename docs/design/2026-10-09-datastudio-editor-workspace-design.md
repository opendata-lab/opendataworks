# Data Studio 编辑器工作台视觉设计

## 现状与目标

左侧已有数据源 → 数据库 → 表/视图分组的懒加载树，但表节点使用多行卡片、数据量底纹和四种统计标签，弱化了层级。三栏独立圆角边框、查询内部卡片和结果卡片占用空间，窄屏工具栏容易拥挤。领导演示需要清晰、克制的数据库工具界面。

## 范围与方向

只修改 Vue 3 / Element Plus 前端展示和局部交互；Java、DataAgent、API、数据库和部署契约不变。保留查询、元数据编辑、血缘、懒加载、Tab 恢复和水平拖拽。用户已确认按第十四版原型1:1落地，正式实施以该版布局、颜色、字号和交互为验收基准。保留原型截图和累计源码补丁用于对照。

内部比较三种方向：压缩现有卡片、数据库编辑器、以搜索为主的资产浏览器。选择数据库编辑器：连续三栏、浅色资源树、白色编辑面、细分隔线和蓝色激活态。

## 设计

- 导航“Agent问答”改为“智能问数”，与已有路由标题一致。
- 顶层明确为“数据源连接”，使用连接图标、连接名称和数据库引擎类型，结构为连接 → 数据库 → 表/视图 → 对象；保持现有数据源 ID、激活/懒加载和查询绑定契约。演示数据中的连接名称改为“演示 Doris 连接”，实际连接保留用户配置名称。
- 左侧提供“紧凑视图 / 完整视图”，默认紧凑；入口为搜索框右侧的视图选项图标，下拉菜单用勾选标记当前模式，避免与排序混用分段按钮。字号统一 10px：简洁模式为 24px 单行对象名；详细模式为 36px 两行节点：首行对象名，次行注释与行数/存储/上下游统计；注释过长截断并提供悬停全文。父节点始终保持 24px。两种模式共用同一棵树，不清空展开、搜索、排序与选中状态；14px 层级缩进、层级引导线；允许多个分支同时展开，点击父节点展开/收起。简洁模式的信息可在悬停和对象详情查看；详细模式统计采用无色块的紧凑文字，低对比度细线保留相对行数分布。保留元数据缺失警告、数据库与分组计数、数据源状态、可视范围统计加载，以及常驻的逐数据源/数据库刷新入口。完整信息仍有悬停提示。
- 删除“数据资源”标题行，将全局刷新和新建表移至搜索框旁；排序收进搜索行右侧的排序图标菜单，菜单按“排序依据 / 排列方向”分组并勾选当前值；移除常驻排序行，顶部只保留一行搜索与工具图标。排序只更新已加载对象分组的叶节点，不重建数据库分组，保留展开与当前选中对象。
- 删除重复的“Data Studio / SQL 工作台”顶部工具栏；新建查询使用标签栏“＋”（空状态保留新建按钮），对象详情显隐移至标签栏右侧；统一外框、移除三栏独立圆角卡片。标签单行、SQL/结果通过分隔条组织。
- 字号采用10/11/12px层级：目录及辅助信息10px，工具栏/标签/结果/详情正文11px，SQL与对象标题12px。标题字重500，概览和访问指标分别14/16px。
- 详情头部按“对象名 → 所属连接 / 数据库 → 独立描述 → 标签与操作”排列；对象名用12px/500字重，描述11px可换行，标签为中性轻底色，完善度为辅助文字。底行标签居左、按钮居右，“编辑”为主按钮，“智能元数据”为次按钮，“删除”移入更多菜单；窄栏底行自动换行，编辑态仅保留取消/保存。
- 右侧详情可收起，保留挂载及编辑状态；元数据各 Tab 同步扁平化；血缘移为独立 Tab，按需打开，移除常驻上下分栏以完整展示对象详情。描述列表继续按实测宽度选择列数。
- 默认左栏 22%（为表名与恢复的统计留出空间）、右栏 28%，下限分别 220px / 320px；窄工作区工具栏换行，避免按钮遮挡。窄屏改为可滚动的纵向排列。

## 中间工作区原型细化

- 查询标签紧贴工具栏，移除内容区的默认留白。执行动作居左，执行作为唯一蓝色主按钮；停止使用图标与文字，存为任务为次操作，重置放入更多菜单。
- 所有查询标签保留可选择连接和Schema的下拉框，表对象身份与执行上下文分别保存。结果行数上限通过“200 行”入口弹出设置，避免数字步进器常驻。
- 结果标签统一中文（执行信息、结果 1、查询历史）；结果工具栏仅保留状态、行数、耗时，时间与批次详情通过悬停及执行信息查看。表格 / 图表使用轻量按钮切换，导出采用有提示的图标。
- 数据网格增加固定序号列、浅色表头、细列分隔与 28px 行高。信息、历史和图表采用同样的扁平布局。保留查询、取消、保存、结果集、图表与导出行为。

## 中间工作区第五版

- 参考 Navicat 查询工具栏，使用“执行 / 停止 / 解释”图标加文字；主动作保留蓝色执行按钮，保存任务作为次操作。
- 所有查询页签均显示可筛选的连接和 Schema 下拉框。表对象页签的执行上下文单独保存在 query 中，切换执行目标不改对象身份与详情；补全和执行使用同一目标。
- 原型解释按钮将选中 SQL（无选中时整段 SQL）转换为 EXPLAIN，通过现有查询流程展示；demo 使用明确的执行计划样例，真实数据库支持须在正式实施时验证。
- 主查询页签与中心内容共用单个边框，选中标签白色底边与内容连接；下方结果页签使用同样的包含式页签，围住当前结果内容，取消蓝色下划线。框架保持至多两层。

## 页签新增与溢出

新增查询加号紧随已显示标签，作为页签栏正常布局项；仅为右侧详情开关预留空间。标签未溢出时不显示左右滚动箭头；超出剩余可用宽度时使用 Element Plus 原生测量与滚动，保持新增按钮可见。关闭标签后箭头自动消失。

## 右侧对象检查器第七版

- 头部按对象名、连接/数据库、描述、标签与操作分层，操作补充图标；字号与中心一致，按钮仅编辑为主色。
- 常驻概览、字段、DDL、血缘、数据新鲜度五个页签，与内容形成包含式结构；引擎配置、访问统计、变更记录进入“更多”菜单，打开时菜单按钮显示当前页名称。所有原有内容与加载逻辑保留。
- 概览采用“归属信息 / 数据规模 / 更新时间”分组和无边框描述列表，字段编辑仍保留对象名和描述。面板实测宽度至少 360px 时两列，更窄退回一列；长时间项跨整行。行数/数据量的趋势入口保留。
- 字段查看态使用紧凑表格，首屏字段名/类型/注释，保留主键/空值/默认值、建议描述与完整编辑表格。
- 字段、DDL、引擎配置、访问、新鲜度、变更和血缘统一中性表头、11–12px 字号、浅色分隔及平直框架，保留各组件自身边框，避免再套卡片。

## 权衡

10px 是用户要求的高密度目录字号，依靠行高、对比度和图标维持定位。简洁模式用于快速定位，详细模式用于信息扫读与比较，去掉卡片边框、彩色标签底色与大面积统计底纹。详情 Tab 在窄面板保留原生滚动导航，优先给 SQL 编辑区域留空间。

## 验证

运行现有导航与 Data Studio 聚焦测试、生产构建；通过本地演示数据驱动真实前端 UI，检查树展开、多个分支共存、打开表、查询/结果、排序、详情显隐与拖拽，以及 1440/1280/窄屏布局。演示数据验证不代表真实数据库 SQL 执行验证。

## 第八版：页签连体结构与其余详情

- 用户否定字段卡片列表，恢复横向对齐的字段表格；查看态优先字段名、类型、注释，主键/空值/默认值仍可横向查看，编辑与智能描述功能保留。
- 查询、结果和详情页签固定实际高度，激活标签底部覆盖分隔线；工具栏背景与激活标签同为白色。限定查询标签选择器为直接子层级，避免影响结果标签。消除原有标签上下空隙与双线。
- DDL 采用带行号的代码浏览区；血缘采用适合窄栏的上下游关系分组，保留表预览、任务与完整血缘入口，不把分组顺序误画成节点间关系。
- 引擎配置按实测宽度排属性，分区表精简首屏列并用展开行保留范围/分桶/副本。访问统计改为四项双列指标和独立审计属性；新鲜度查看态去描述表格边框；变更记录使用时间顺序列表，保留快照和版本对比操作。
- 演示环境补充分区、新鲜度及元数据版本样例接口，仅用于原型浏览，不修改真实后端契约。

- 第九版局部图标校正：编辑使用线性铅笔，智能元数据使用线性星芒；统一14px、1.7px线宽、4px文字间距。生成中仅展示按钮加载图标，避免双图标。行为与演示禁用状态保留。

- 第十版详情显隐入口：查询标签栏右端固定26px图标按钮，16px线性右侧面板图标，箭头随显隐方向变化；悬停提示“隐藏/显示对象详情”，aria-expanded 与 aria-controls 对齐状态。移除详情标题栏重复的关闭按钮；标签栏为图标预留40px，保留加号与溢出滚动。

- 第十一版完整树视图压为两行：第二行注释居左、统计居右，行高36px；10px字号、元数据警告、统计加载与相对行数细线保留。紧凑模式及父级节点仍为24px单行，切换保留树展开和选中状态。

- 第十二版树配色：紧凑/完整模式共用中性灰背景#f6f6f6，主文字#30343b、辅助文字#666b73；图标和统计改为统一灰色，移除上下游的绿/紫色和连接图标绿色。蓝色仅用于选中行文字/图标与左侧标记，普通悬停用中性灰；元数据缺失警告仍保留红色语义。搜索、层级引导线同步使用中性灰，完整视图保留36px两行。

- 第十三版：响应左栏灰色与中间/右侧不协调反馈，目录改为白色画布，与工作区共用文字和边框变量；灰色仅用于悬停/辅助信息，蓝色选中态保留。紧凑24px与完整36px两行继续保留。

- 第十四版字体协调：左树继续10px；工作区工具、标签、结果及检查器正文统一11px；SQL与对象标题12px。新增页面级三档字号变量，标题字重收敛至500，概览/访问指标分别14/16px；SQL仅本页调整，共享编辑器不改。检查紧凑/完整目录及所有详情兄弟页签。

## 正式实施与验收

2026-10-09用户确认按第十四版原型1:1重构。实现保留在正式frontend源码，不再恢复为HEAD。沿用Vue/Element Plus/Sass及现有composable边界；清理原型迭代遗留的重复样式和无用声明，同时保持最终计算样式不变。demo样例仅留在demo mock层。验证导航、目录懒加载/排序保留状态、对象身份与执行连接分离、执行/停止/解释、详情各页/编辑/版本，以及正式构建；真实API smoke依据本地服务可用情况执行并明确报告范围。

- 正式落地补充激活态：连接测试成功后连接图标绿色#2f9167；Schema成功加载对象列表（含空库）后图标同色，未激活/停用保留灰色。状态来自现有连接与目录缓存，与蓝色对象选中行独立。两种目录模式同步，补充状态回归。查询执行目标持久化为version1快照可选字段，历史/存为任务使用该目标，不改对象身份。

- 最终补充：右栏“数据新鲜度”改为常驻标签；更多仅保留引擎配置/访问统计/变更记录。窄栏血缘关系分组、对象名和空态10px，说明保持10px；标签10px/16px高，标题和完整血缘入口继续11px。

正式前端实现与本地验证已完成，源码保留在工作区。23个测试文件共186项通过，生产及演示构建通过；原型与实现的9组布局/计算样式测量一致。真实数据库联调未运行，详见[验证记录](../reports/2026-10-09-datastudio-editor-workspace-validation.md)。
