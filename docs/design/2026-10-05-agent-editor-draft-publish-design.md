# 智能体工作台：草稿、调试与发布

## 现状与问题

DataAgent 独立 Vue 应用的 `AgentDetailView.vue` 使用分组表单，保存直接更新 `da_agent_profile`。正式聊天创建话题时读取该表并冻结智能体快照。因此，保存等同上线，缺少发布前的真实调试。

## 范围与界面

按已确认的本地原型实现三栏工作台，复用其颜色、间距、控件和响应式布局，去掉模拟数据及多余小字。左栏显示真实内置提示词（只读）及自定义提示词；中栏配置描述、Skills、MCP、工具、数据范围、可见范围、预设问题和高级设置；右栏提供真实对话预览、运行记录和发送/停止调试。保存草稿与发布为两个操作。

桌面宽度（大于 768px）始终三栏并排，列宽随空间收缩，不将右栏放到下一行。手机窄屏改为纵向三块。模型使用 SDK 的自定义下拉组件（不依赖宿主 Element Plus、不使用原生 select），位于输入框左下角，最大宽度 170px；特别窄的栏内发送按钮可换行，避免挤坏选择器。

详情路由复用主页面的导航侧栏、品牌和用户菜单，不使用独立顶栏。工作台样式局部生效。正式聊天的导航、历史与路由保持原有实现。Skills、MCP 标题右侧的“＋ 配置”点击后在列表下方展开选择框，添加后收起。预览完整复用 conversation SDK，包括输入框。真实取消验证发现：后端取消接口返回仍在运行的任务，SDK 却立即断流，造成输入框永久禁用。修正 SDK 的通用取消处理：接受取消但仍为活动状态时继续消费事件，只在真实终态关闭回复；覆盖正式聊天与预览的共用行为。

## 共享对话组件（2026-10-06）

主对话和调试复用同一个 Composer：输入自动增高、Enter/Shift+Enter、中文输入、发送/停止、附件和快捷命令逻辑不再在编辑页复制。工具栏放进输入框底部，模型在左侧、发送/停止在右侧；保留主页面权限模式和文件能力。调试权限模式仍为 default，权限确认卡片正常工作；快捷命令仅列出草稿选择的 Skills，不伪造运行时内置命令。

增加可选 SDK `beforeSend(context)` 异步宿主钩子，普通发送、预设问题和错误重试都经过它，返回 false 中止；未配置钩子的宿主保持原有行为。编辑页在此保存草稿、核验版本并将旧预览地址清空，由既有 endpointResolver 创建新草稿话题，不在发送过程中卸载组件。保存失败、并发编辑未保存、附件所属旧快照或路由已变化时不提交。新话题上传同样先保存并冻结草稿；若配置变化后已有旧话题附件，提示重新添加，避免将旧工作区路径带进新话题。

SDK 保持无外部运行依赖；模型自定义下拉由 SDK 提供，支持键盘导航、Escape、选择和点击外部关闭。两页共用局部对话样式：浅蓝用户气泡、深色文字、14px 正文、1.7 行高，宽度和左右留白由宿主容器决定。发布保护、预览历史隔离和数据契约不变。

切换运行调试时只隐藏消息区域，保持共用输入框可见。SDK 通过 `dataagent-composer-resize` 上报实际输入区高度，运行记录覆盖层据此留出空间，附件或多行输入也不会被挡住。模型菜单按输入卡片内剩余宽度收缩，窗口尺寸变化时关闭菜单。

## 数据与接口

- DataAgent FastAPI/MySQL：新增 `da_agent_draft`，保存完整配置 JSON、单调递增 revision、published_version、已发布配置 JSON、最近调试 task/revision。原 `da_agent_profile` 继续只承载已发布配置。
- 为现有已发布配置惰性创建 revision=1/version=1 的草稿。创建智能体只创建未发布草稿，不进入公开目录。管理员目录合并已发布和草稿，普通用户目录仍读取发布表。
- 编辑读取、草稿保存、创建和发布通过管理员接口；保存和发布需要 expected_revision，冲突返回 409。配置变化立即使旧调试失效。相同配置保存不增加 revision。
- 新增管理员预览话题/任务接口：以草稿快照创建真实话题，调用现有任务提交及协调器。复用已有 SSE、权限交互、问题回答、消息持久化与取消接口。
- 话题新增 `is_agent_preview`。正式历史和管理会话列表排除预览；认证开启时非管理员的所有话题/任务访问谓词拒绝预览。
- 开始调试前锁定草稿并撤销上次调试批准，生成 preview_token；提交任务后仅同一 token/revision 可关联结果，避免并发请求乱序恢复旧批准。发布在单个 MySQL 事务中锁定草稿，核验 revision、最近调试成功及其快照匹配后，写入发布表并推进版本；重复发布相同配置拒绝。发布表写入复用同一 SQL 实现。
- 原 POST `/agents` 改为创建草稿；原 PUT `/agents/{id}` 改为保存草稿，需 expected_revision。GET configuration 保持读取发布配置，新编辑读取使用 GET draft。这是管理接口契约变更；所有仓库内调用同步更新。

## 对话兼容性

现有话题和任务的快照不回写。发布后仅新建正式话题读取新配置。预览从不更新发布表，不进入正式历史，不使用正式话题 ID。内置提示词从运行时使用的模板读取，禁止前端复制或提交覆盖。

## 风险与取舍

成功调试表示真实运行已完成，不表示业务结果经过人工审核，因此发布仍需用户勾选确认。外部模型、MCP 和 Skills 自身修改不在智能体版本管理范围内。管理员并发编辑使用乐观锁；发布使用行锁。保留真实预览消息以支持刷新恢复，清空对话会删除该预览话题。

## 影响的技术栈

涉及 DataAgent Vue 3/Element Plus、conversation SDK、FastAPI/Pydantic、PyMySQL 和 Alembic。主 Java 后端及部署拓扑不改变。部署需先运行 Alembic 升级再同批更新前后端；旧服务仍使用发布表，旧前端向新后端保存时会收到 422，不会直接上线。演示适配器也隔离草稿与发布目录；演示数据不能验证真实模型运行，因此演示调试明确返回不可执行，不能取得发布批准。
