# 智能体工作台实施计划

设计：[草稿、调试与发布](../design/2026-10-05-agent-editor-draft-publish-design.md)

1. 增加 Alembic 草稿表及预览话题标识；提取已发布配置事务内写入方法。
2. 实现草稿读取/保存/目录/创建/删除、版本冲突及发布校验，接入管理 API 和真实任务提交。
3. 隔离正式话题目录及非管理员对预览的访问；保留原有快照逻辑。
4. 将 AgentDetailView 替换为原型三栏布局，保留全部配置能力及只读访问；接入 SDK 对话、运行记录、停止/清空、草稿失效和发布确认。
5. 更新 API client、管理员智能体目录及详情路由布局。详情复用主页面侧栏导航，Skills/MCP 标题按钮控制下方选择框，模型选择置于输入框左下角。正式聊天不修改布局和 transport。
   同步演示适配器的草稿契约；修正 SDK 在异步取消被接受后过早断流的问题，覆盖活动状态取消、终态取消及取消返回晚于终态的竞态。
6. 添加草稿/发布/并发/预览隔离回归测试及前端关键状态测试。按 `.nvmrc` 执行相关 Vitest 和构建。
7. 使用本地 Podman MySQL（实际映射 3306）与 Redis 6379、`.venv-py313`、真实模型开展 HTTP 和浏览器 smoke，验证保存不影响发布、真实调试、SSE、发布、新旧对话快照和正式历史隔离，记录环境及未覆盖项。
8. 在 `docs/reports/` 记录验证和截图。上线先升级数据库，再发布后端和前端。回退应用可直接继续使用发布表；保留新增草稿及预览字段，降级迁移会删除草稿，需先备份。

9. 按确认的对话统一方案改造 SDK Composer、模型自定义下拉和 `beforeSend` 钩子；删除编辑页外部输入框与重复模型/输入状态。主对话保留附件、权限与命令配置，两页共享消息呈现样式。
10. 验证发送前异步校验、拒绝发送、重复提交、重试、模型键盘选择、附件与原命令交互；运行 SDK 和宿主前端测试、类型检查、SPA/SDK 构建。真实浏览器覆盖主对话和草稿预览的发送/SSE/取消及窄屏，确保修改草稿后新预览快照正确，记录准确环境与清理结果。
